# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

**Do not open public issues for security reports.**

Email maharana.sarkar2000@gmail.com with:

- Description and impact
- Steps to reproduce / PoC
- Affected versions

We aim to acknowledge within 48h and provide a fix timeline within 7 days.
Coordinated disclosure is appreciated; we will credit reporters unless anonymity is requested.
